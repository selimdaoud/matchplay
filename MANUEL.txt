MATCHPLAY LIVE — MANUEL D'UTILISATION
======================================
Application de suivi live pour parties de golf :
  - Matchplay : duel trou par trou
  - Strokeplay : score en coups, trou par trou

Accès : https://compet.golf/matchplay/


════════════════════════════════════════
PERSONAS
════════════════════════════════════════

  1. L'ORGANISATEUR  — crée les parties, gère la journée
  2. LE MARQUEUR     — saisit les résultats trou par trou
  3. LE SPECTATEUR   — suit les scores en direct


════════════════════════════════════════
1. L'ORGANISATEUR
════════════════════════════════════════

AVANT LA JOURNÉE
  Définir le code de session dans l'environnement du serveur :
    sudo env SESSION_CODE=moncode npm start

  Ce code est annoncé oralement le jour J. Il protège la création
  des parties et les actions d'administration : sans lui, personne
  ne peut créer, masquer ou restaurer une partie.

LE JOUR J

  Créer une partie
  ─────────────────
  1. Aller sur https://compet.golf/matchplay/new
  2. Saisir le code de session
  3. Choisir le type de partie :
       - Matchplay : joueur de référence + adversaire
       - Strokeplay : joueur seul
  4. Choisir le parcours :
       - None : pas de parcours sélectionné
       - Bossey : charge les pars et scores moyens du parcours
       - Esery : option disponible, données à compléter
  5. Remplir le titre et les joueurs demandés
  6. Cliquer "Créer le match"
  7. La page affiche :
       - L'URL du marqueur (ex: https://compet.golf/matchplay/match/a3f2c1)
       - Un QR code à scanner
  8. Faire scanner le QR code au marqueur, ou lui envoyer le lien

  Répéter l'opération pour chaque partie de la journée.

  Gérer les parties
  ─────────────────
  La liste des parties du jour apparaît en bas de la page /new
  après saisie d'un code de session valide.

  Chaque ligne affiche le titre, les joueurs et le nombre de trous
  déjà saisis. Le titre est cliquable et ouvre la page de saisie.

  Bouton "Masquer" : cache une partie du live feed (ex: test,
    erreur de création). La partie reste accessible via son lien.
  Bouton "Restaurer" : remet une partie masquée dans le live feed.

  Ces actions nécessitent le code de session dans le champ du haut.

  Partager le live
  ────────────────
  URL publique à diffuser aux spectateurs :
    https://compet.golf/matchplay/live

  Aucun code requis pour y accéder.

  Réinitialiser une session
  ─────────────────────────
  Pour effacer les données d'une session :
    node scripts/reset-session.js

  Le script liste les sessions disponibles, demande une confirmation,
  puis supprime les trous matchplay, les matchs et la session elle-même.

  Attention : opération irréversible. À vérifier avant usage si des
  parties strokeplay existent dans la session.


════════════════════════════════════════
2. LE MARQUEUR
════════════════════════════════════════

ACCÈS
  Ouvrir le lien reçu de l'organisateur, ou scanner le QR code.
  URL de la forme : https://compet.golf/matchplay/match/[code]

  → Bookmarker cette page sur son téléphone.
  → Ne pas partager ce lien : c'est la clé d'accès en écriture.


SAISIE MATCHPLAY
  Sur la page, trois grands boutons apparaissent pour le prochain trou :
    GAGNÉ   → le joueur de référence remporte le trou (+1)
    ½       → trou partagé (score inchangé)
    PERDU   → le joueur de référence perd le trou (-1)

  Appuyer sur le bouton correspondant au résultat.
  Le score cumulé se met à jour immédiatement.

  Si un parcours est sélectionné et renseigné, la page affiche aussi
  le par et le score moyen du trou en cours.

  Corriger un trou matchplay
  ──────────────────────────
  Dans l'historique, appuyer sur la case résultat du trou à corriger.
  Une fenêtre s'ouvre avec les 3 choix.

  Sélectionner le bon résultat. L'ancien résultat est conservé en base
  comme événement corrigé ; seul le résultat courant change.

  Il n'y a pas de suppression possible, uniquement correction.


SAISIE STROKEPLAY
  Sur la page, un compteur de coups apparaît pour le prochain trou.

  1. Ajuster le score avec les boutons − et +
  2. Cliquer "Enregistrer trou X"
  3. Le total se met à jour immédiatement

  Les scores acceptés vont de 1 à 20 coups par trou.
  La partie est considérée terminée après le trou 18.

  Si un parcours est sélectionné et renseigné, la page affiche :
    - le par du trou en cours
    - le score moyen du champ sur ce trou
    - l'écart du score saisi par rapport au par
    - l'écart du score saisi par rapport à la moyenne

  L'historique affiche aussi les écarts cumulés au par et à la moyenne.

  Corriger un trou strokeplay
  ───────────────────────────
  Dans l'historique, appuyer sur le score du trou à corriger.
  Ajuster le nombre de coups avec − et +, puis confirmer.

  Comme en matchplay, la correction remplace le score courant tout en
  conservant l'ancien enregistrement en base.


MODIFIER LES NOMS
  Matchplay : les champs "Joueur de référence" et "Adversaire" sont
  éditables directement dans la page.

  Strokeplay : le champ "Joueur" est éditable directement dans la page.

  Modifier le champ puis le quitter pour sauvegarder.


FIN DE PARTIE
  Matchplay
  ─────────
  Quand le match est mathématiquement terminé (le leader ne peut plus
  être rattrapé), les boutons de saisie sont remplacés par un bandeau
  indiquant le résultat final (ex: "4&3", "2 UP").

  En cas d'égalité après le trou 18, la saisie continue en play-off
  trou par trou.

  Strokeplay
  ──────────
  Après le trou 18, la saisie est remplacée par un bandeau indiquant
  que la partie est terminée avec le total de coups.

  Dans les deux cas, il reste possible de corriger un trou dans
  l'historique si besoin.


BOUTONS DE LA BARRE D'OUTILS
  "Copier le lien live" → copie l'URL publique /live à partager
  "Voir l'audit"        → ouvre l'historique complet des saisies
                          matchplay et de leurs corrections

  Note : l'écran d'audit affiche actuellement les événements matchplay.
  Les scores strokeplay restent visibles et corrigeables dans l'historique
  de la page marqueur.


════════════════════════════════════════
3. LE SPECTATEUR
════════════════════════════════════════

ACCÈS
  https://compet.golf/matchplay/live

  Aucun code, aucune inscription. Page accessible à tous.
  Les scores se rafraîchissent automatiquement toutes les 5 secondes.

NAVIGATION
  La page affiche la liste de toutes les parties visibles de la session.
  Les parties masquées par l'organisateur n'apparaissent pas.

  Le titre de la page s'adapte au contenu :
    - Matchplay Live si toutes les parties sont en matchplay
    - Strokeplay Live si toutes les parties sont en strokeplay
    - Golf Live si les deux formats sont présents

  Appuyer sur une partie ouvre la vue détaillée avec l'historique trou
  par trou. Le bouton "← Tous les matchs" revient à la liste.


════════════════════════════════════════
LEXIQUE SCORES
════════════════════════════════════════

  Matchplay
  ─────────
  AS       → égalité (all square)
  X UP     → le joueur de référence mène de X trous
  X DOWN   → le joueur de référence est mené de X trous
  X&Y      → match terminé : gagné X UP avec Y trous restants
             (ex: 3&2 = gagné 3 UP avec 2 trous à jouer)
  Play-off → égalité après le trou 18, prolongation trou par trou

  Résultats par trou :
    G  (vert)   → trou gagné par le joueur de référence
    ½  (gris)   → trou partagé
    P  (rouge)  → trou perdu par le joueur de référence

  Strokeplay
  ──────────
  Total     → somme des coups saisis
  Départ    → aucun trou saisi
  Terminé   → 18 trous saisis
  Vs par    → score du joueur moins le par
  Vs moy.   → score du joueur moins le score moyen du champ
